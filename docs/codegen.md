# Codegen — operating manual

This repo's `Sources/QVACClient/Generated/` directory is produced by the
`scripts/codegen/` pipeline from `@qvac/sdk@0.10.2` (pinned in
`scripts/codegen/package.json`). CI fails any push where re-running the
codegen would change those files — see
[`.github/workflows/ci.yml`](../.github/workflows/ci.yml) job
`codegen-drift`.

## How to regenerate

```bash
cd scripts/codegen
pnpm install --frozen-lockfile     # only needed when deps changed
pnpm run run                       # re-emits Sources/QVACClient/Generated
cd ..
git status -- Sources/QVACClient/Generated/
```

If the diff is non-empty, commit it.

## How to interpret a CI failure

The `codegen-drift` job in CI runs the same `pnpm run run` and then
checks `git diff --exit-code Sources/QVACClient/Generated/`. A failure
means:

1. **You edited a generated file by hand.** Don't — every generated file
   starts with `// Auto-generated by scripts/codegen — DO NOT EDIT BY HAND.`
   Move your change into the generator (`scripts/codegen/src/emit/*.ts`)
   or the type-mapping utility (`scripts/codegen/src/util/typemap.ts`)
   and re-run codegen.
2. **You updated `scripts/codegen/package.json`'s `@qvac/sdk` pin.**
   Re-run codegen and commit the diff. Update
   [`docs/codegen-deferred.md`](./codegen-deferred.md) and
   [`docs/qvac-sdk-internals.md`](./qvac-sdk-internals.md) if the SDK's
   exported surface has changed.
3. **You updated the codegen pipeline.** Re-run and commit.
4. **You ran codegen on a different platform / Node version.** The CI
   uses Node 24 + `bare-runtime` v1.28.5 + TypeScript 5.9.3 (all pinned
   in `scripts/codegen/package.json`). If your local versions differ,
   align them.

## What lives in `Sources/QVACClient/Generated/`

- `ErrorCodes.swift` + `ErrorCodes.json` — typed error enums from
  `SDK_CLIENT_ERROR_CODES` / `SDK_SERVER_ERROR_CODES` (YK-181).
- `Models/*.swift` — Codable DTOs from the M1 allowlist (YK-179). The
  long tail of `@qvac/sdk` types not yet generated is tracked in
  [`docs/codegen-deferred.md`](./codegen-deferred.md).

Everything else under `Sources/QVACClient/` is hand-written and lives
**outside** the codegen surface; CI doesn't touch it during the drift
check.

## Bumping `@qvac/sdk`

1. Edit `scripts/codegen/package.json` — change the `@qvac/sdk` pin.
2. `pnpm -C scripts/codegen install` (refreshes lockfile).
3. `pnpm -C scripts/codegen run run` (regenerates).
4. Review the diff in `Sources/QVACClient/Generated/`. New types may
   need to be added to the allowlist in
   `scripts/codegen/src/index.ts` (`CODEGEN_TYPES_ALLOWLIST`).
5. Refresh hand-written docs:
   - `docs/qvac-sdk-internals.md` — version table + handler counts +
     error code counts.
   - `docs/codegen-deferred.md` — entries that became extractable.
6. Run full test suite: `swift test` and `pnpm -C scripts/codegen test`.
7. Commit. CI re-verifies on push.
